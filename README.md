# Unknown person's face detector system


This project is a mini project developed as part of my college coursework. The Unknown Person's Face Detector System is designed to detect and identify faces in images or real-time video streams, flagging faces that are not already known or registered in the system.


**Table of Contents:**


1.Overview


2.Features


3.Technologies Used



**Overview:**


This system uses computer vision techniques to detect faces and compare them against a pre-registered set of known faces. If a face is not recognized, it will be flagged as "unknown." The goal of this project is to showcase basic facial recognition technology and demonstrate how such a system can be implemented for security and surveillance applications.


**Key Features:**


Face Detection: Detects faces in images and video.


Face Recognition: Identifies faces based on previously stored facial data.


Unknown Person Alert: Flags unknown faces, highlighting them as unrecognized.


Real-time Processing: Capable of detecting faces from live webcam feeds.


**Technologies Used:**


Python: Main programming language used for the project.


OpenCV: Used for face detection and video processing.


Haar Cascade Classifier: Utilized for detecting faces in images and video.


dlib: For more accurate facial recognition (optional, depending on your implementation).
